# Banco360
Pagina web basica de banca en linea para que el usuario pueda gestionar su cuenta y transacciones.

## Características principales:
- **Dashboard**: Vista general de saldos y transacciones recientes.
- **Transferencias**: Módulo completo para envío de fondos entre cuentas y bancos.
- **Pago Móvil**: Interfaz rápida para pagos interbancarios inmediatos.
- **Depósitos**: Sistema intuitivo para la entrada de dinero a la cuenta.
- **Modo Oscuro/Claro**: Soporte completo para personalización visual.
